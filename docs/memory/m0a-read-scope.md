# M0A 核心记忆读取边界

状态：独立开发工作树中的首批实现，尚未合并部署。数据库和运行配置没有迁移或改写。

## 已实现

- 新增不可变 MemoryReadScope。频道回答显式指定当前频道；工作区管理审查由已认证调用点显式选择 workspace_review。缺少或工作区不匹配的 scope 直接拒绝。
- 通过 PostgreSQL 的来源与活跃状态先取得获授权段落 ID，在 Qdrant 使用 HasIdCondition 约束候选，再由 SQL 复核返回记录；不要求给既有向量补写来源 payload 或重建线上索引。
- 关系召回只接受获授权来源段落的关系；频道来源不明、无段落的关系不进入频道回答。
- Episode 必须属于当前频道，且每个来源段落都已获授权。混合来源、无来源或不完整的聚合记录不进入频道回答。
- 详情和来源追溯先核对权限，不能通过猜测 ID 绕过检索过滤。工作区聚合实体画像在频道工具中暂不可展开。
- 在线历史、插件自动核心回忆和主动搜索／详情／追溯工具均传递频道 scope；管理员工作区握手显式传递管理 scope。
- 插件不再为未绑定频道读取第一个工作区。未绑定频道仍可正常对话，核心长期记忆层跳过。
- 修复 SQLite 事实更新：新值使用自己的 confidence，不再继承被替换旧值的最大置信度。管理员事实保护规则继续保留。

核心完整代码以及本次修改的插件源码和新增测试执行 poe lint --no-cache。依赖中的 Pydantic 与 Tortoise 弃用警告另行记录，不在本包改动中扩散修复。

## 部署前检查

核心与插件必须成套发布，外部调用方如果直接调用核心记忆 API 也必须补 scope。没有来源的旧记录、其他频道的记录与工作区聚合实体不再自动用于频道回答；这会减少旧系统中不受约束的召回，需在后续显式共享授权设计中恢复合法的共享范围。

M0A 的来源过滤会读取当前频道全部活跃段落，适合当前千条级数据。尚未做大规模基准；扩容前应替换为权威 ID 预筛或来源 payload 过滤，并保留 SQL 复核。

M0A 尚未接入 grant 表、受众 revision、事实版本库、持久任务或统一 ContextBuilder。既有 SQLite 共享组、跨会话原文工具及管理员页面的旧规则未在本包重写，因此本包不能称为全系统统一授权已经完成。跨会话共享与删除／撤权传播是后续独立验收项。

本次只修复后续事实更新的置信度处理，不猜测或批量修复历史事实。完整版本与证据保留仍由 M1 实施。
