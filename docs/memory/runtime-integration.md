# 统一事实运行时接入

本批在分支 `local/memory-runtime-20261021` 实施，续建基线标签 `memory-v11-foundation-20261021`。未部署生产。

## 已接入路径

- 人类消息落库后，通知绑定该次落库 ID；服务模式进入持久队列，停止通知旧核心抽取调度器。机器人输出仍可用于既有消息历史，不作为新事实来源。
- MemoryFactRuntime 随 Agent 初始化和关闭启动／停止；默认 `MEMORY_FACT_WORKER_ENABLED=false`，真实影子调用另需 `MEMORY_FACT_SHADOW_MODEL_ALLOWED=true`。
- 补扫从最早已提交消息分页，不只取最近 30 条。进度只用作一轮内的扫描优化，扫完归零；重启重新扫描，通过持久来源修订和任务唯一键去重。
- 模型适配器限制输入大小及最多六条候选。模型不能指定 actor、来源或管理员标识；来源和 subject 绑定发言人，原文引用逐字核对。缺少人格／操控／角色扮演判断字段时输出无效；低置信度、第三方推断和污染候选不发布。
- 来源修订覆盖频道、适配器、用户、发送者角色、时间、正文和撤回状态，入队后发生身份／正文变更会在调用模型前被阻断。
- scope 为 service 时，history 注入只读取统一事实服务；天使退出旧事实注入与事实抽取，但独立关系事件处理继续运行。

## 切换与提交锁

legacy_fact_write 与 set_mode 共用频道行锁，再检查事实 scope。旧核心段落提交、CC 语义段落提交、天使自动事实／画像／摘要和部分手动记忆工具已接此门。抽取前检查用于省模型调用，提交时检查用于拒绝迟到写入，两者均需要。

人格模型判定移到提交锁之外；事务只覆盖实际数据库提交。天使事实发布与关系发布拆为两个方法，关闭事实写入不会同时关闭好感度事件。

这不等于所有旧入口已接管：知识笔记、管理 router、历史编号迁移、完整工具写入 facade 和旧数据同步仍需盘点接入。不得仅调用 set_mode 就对线上宣称已完成灰度。正式切换前仍须停旧任务、追平增量、核对投影和演练回滚。

## 门控

assertion 增加 min_favor，范围 0..100。访问授权先限定来源和受众，expression_ceiling 只收紧授权集合；该参数只能由服务端关系策略传入，不能作为模型自选权限。默认 ceiling 为 0：未提供受验证关系策略时，不放出高门槛事实。

普通自动更正和同值补证不能降低已有表达门槛；管理员明确编辑可调整。管理员审查与对话表达用途分开。旧 SQLite 允许的超大门槛值需要在历史迁移时按现有阶段语义显式映射，不能直接导入或静默压低。

Core history 当前只按原记忆块上限做保守字节预算，不宣称已经统一整个模型窗口。关系片段尚未接带来源依赖校验的提供器，service 模式暂不注入旧聚合关系画像；关系数据、事件与原状态机继续保留。

history 接口目前返回字符串。完整 EvidenceBundle 贯穿后续模板并在真正发送模型请求前再次复核，仍需接入；目前只能保证服务读取及 build 时校验，不能把它描述成完整的发送前撤权防护。
