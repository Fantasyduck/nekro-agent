# Agent 上下文编排接口

MemoryContextBuilder 位于 Agent 编排层，不接管事实或好感度的存储。每次 build 只执行一次事实 recall，拼接只读人格、当前任务、完整事实、单份近期历史和经权限校验的关系片段。已使用的 fact ID 保留在 ContextBundle 中，可在发送前再次 validate。

预算显式扣除输出、工具、安全和模板开销；长期事实另有上限。条目超限整条舍弃，不截断半条事实或人格规则。默认按 UTF-8 字节保守计量，并明确报告估算方式；可由调用方注入模型 tokenizer，不在离线环境下载分词资源。此处计量的是所构建文本，其他模板与消息封装开销必须由调用方填写 prompt_overhead。

关系提供器与验证器必须同时存在才能使用关系片段；缺少验证器、来源不明、超时或提供器失败均使用中性结果。发送前关系验证失效时拒绝继续使用旧 bundle，不因亲密度扩大事实权限。

本批提供可测试的编排接口，尚未替换 history.py 和天使原有 render_prompt hook。旧注入必须在 M3 接入阶段一并退出，不能同时开启两种编排器。未宣称当前线上已经消除重复召回或完成全模型预算统一。
